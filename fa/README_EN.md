# WCH CH32 Application Notes — English Guide

## Overview

The `fa` directory contains bilingual Persian-English guides for WCH CH32 Application Notes. Each AN has a dedicated directory containing its guide and, where available, links to the Persian PDF/HTML editions and supporting media. This file provides the English-language overview and index of the available guides.

## Directory Structure

| Path | Description |
|---|---|
| `ANxxxxx/README.md` | Bilingual guide for an application note |
| `ANxxxxx-FA.html` | Browser-readable Persian edition, when available |
| `ANxxxxx FA.pdf` | Persian PDF edition, when available |
| `media/` | Supporting images and diagrams |

## Publication Status

The publication status of each application note is determined by the PDF and HTML files actually available in the repository. The presence of a README file or directory alone does not indicate that a translation has been completed.

## Engineering Notes

- Check the datasheet and reference manual for the exact MCU model and package.
- Verify peripheral names, register definitions, values, and units against the original documentation.
- Validate all designs and examples on real hardware before using them in a production product.
- Do not assume that a feature or configuration supported by one MCU model is available on another.
