## معرفی مخزن

این مخزن مجموعه‌ای از یادداشت‌های کاربردی (Application Notes یا AN) برای میکروکنترلرهای خانواده **WCH CH32** است. هدف این اسناد، ارائه راهنمای عملی برای استفاده از قابلیت‌های MCU، طراحی سخت‌افزار، پیکربندی نرم‌افزار، راه‌اندازی Peripheralها، عیب‌یابی و بهینه‌سازی عملکرد در کاربردهای واقعی است.

مطالب این مجموعه مکمل دیتاشیت (Datasheet) و راهنمای مرجع (Reference Manual) هستند؛ یادداشت‌های کاربردی معمولاً روی یک قابلیت یا مسئله مشخص تمرکز می‌کنند و مراحل پیاده‌سازی، نکات طراحی و محدودیت‌های عملی آن را توضیح می‌دهند.

## راهنمای انتخاب و مطالعه

1. ابتدا شناسه یا موضوع موردنیاز را در جدول زیر پیدا کنید.
2. برای مطالعه محتوای فارسی و مشاهده وضعیت ترجمه، روی «راهنمای فارسی» کلیک کنید.
3. برای مراجعه به متن اصلی، مثال‌ها و مستندات چینی، از پیوند «نسخه اصلی» استفاده کنید.
4. در طراحی نهایی، مشخصات الکتریکی پایه‌ها و محدودیت‌های قطعه را از دیتاشیت همان مدل بررسی کنید؛ برای جزئیات رجیسترها و رفتار Peripheralها نیز Reference Manual را مرجع قرار دهید.
5. کدها و تنظیمات نمونه را با مدل دقیق MCU، نسخه کتابخانه، ابزار توسعه و سخت‌افزار خود تطبیق دهید و پیش از استفاده در محصول نهایی، آزمایش عملی انجام دهید.

## نمایه و جست‌وجوی اسناد

فایل [Index.csv](Index.csv) نمایه جدولی اسناد را ارائه می‌کند و برای جست‌وجوی شناسه‌ها و موضوعات کاربردی است. این فایل در نسخه فعلی شامل اطلاعات فهرست‌بندی منبع اصلی است؛ ممکن است توضیحات آن به زبان چینی باشد. برای وضعیت ترجمه فارسی، راهنمای هر یادداشت در پوشه `fa` را بررسی کنید.

## نکات فنی و مسئولیت استفاده

- یادداشت کاربردی جایگزین Datasheet، Reference Manual، Errata یا مستندات رسمی ابزار توسعه نیست.
- شماره قطعه، پکیج، نسخه سیلیکون، ولتاژهای مجاز، فرکانس کاری و محدودیت‌های پایه‌ها را پیش از پیاده‌سازی بررسی کنید.
- مثال‌های نرم‌افزاری ممکن است به نسخه مشخصی از MounRiver Studio (MRS)، کتابخانه Peripheral، کامپایلر یا Firmware وابسته باشند.
- در موضوعات حساس مانند تغذیه، کلاک، حافظه، USB، RF، EMI و پروگرام، طراحی شماتیک و PCB و همچنین نتایج اندازه‌گیری را مستقل اعتبارسنجی کنید.
- در صورت مشاهده خطا یا ابهام، از بخش Issues مخزن برای ثبت گزارش استفاده کنید. هنگام گزارش، شناسه AN، مدل MCU، نسخه ابزار، مراحل بازتولید و نتیجه مورد انتظار را درج کنید.
