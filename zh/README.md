# اسناد اصلی WCH CH32 / Original WCH CH32 Documents

این پوشه اسناد اصلی چینی WCH را نگهداری می‌کند. برای راهنماهای دوزبانه فارسی و انگلیسی و فایل‌های ترجمه‌شده، پوشه [fa/](../fa/) را ببینید.

This directory stores original WCH Chinese documents. For bilingual Persian-English guides and available translations, see [fa/](../fa/).

## ساختار / Structure

هر یادداشت در زیرپوشه‌ای با شناسه AN قرار دارد. فایل‌های اصلی Markdown و PDF در صورت ارائه منبع در همان مسیر نگهداری می‌شوند.

Each application note is stored in a subfolder named after its AN identifier. Original Markdown and PDF files are retained when supplied by the source.

## راهنمای فنی / Technical Guidance

- متن اصلی را با راهنمای دوزبانه همان شناسه مقایسه کنید. / Compare the source with the bilingual guide for the same AN ID.
- برای مقادیر الکتریکی و رجیسترها به Datasheet و Reference Manual مراجعه کنید. / Refer to the datasheet and reference manual for electrical limits and register details.
- مثال‌ها را پیش از استفاده در محصول روی سخت‌افزار هدف آزمایش کنید. / Test examples on target hardware before production use.
