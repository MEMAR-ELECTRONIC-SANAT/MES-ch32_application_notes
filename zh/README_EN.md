## About This Directory

The **zh** directory contains the original Chinese technical documentation published by **WCH** for the **CH32 microcontroller family**. It provides direct access to application notes (AN), technical explanations, examples, tables, figures, and related diagrams.

This collection serves as the primary-language reference for engineers, hardware designers, and firmware developers. It also makes it easier to compare translated documents with the original source and verify technical details against WCH documentation.

## Collection Contents

The current directory contains **49 application notes**. Both formats are available for every listed note:

- **Markdown (.md):** Convenient for reading on GitHub, searching text, and reviewing document structure.
- **PDF (.pdf):** Paginated documents suitable for offline reading, printing, and archiving.
- Images and diagrams referenced by Markdown files are stored in each note's media subdirectory.

> **Note:** The documents in this directory are written in Chinese and represent the original WCH source documents. For Persian translations and their publication status, visit the [fa directory](../fa/).

## How to Use This Collection

1. Select the required application-note ID from the table.
2. Open the **Markdown** file for online reading and text search.
3. Open or download the **PDF** for the paginated document, printing, or offline use.
4. Note-specific figures and diagrams are stored in the corresponding media subdirectory.
5. For Persian guides and translated files, visit the [Persian documentation index](../fa/README.md).

## Document Index

The [Index.csv](../Index.csv) file provides a tabular index of the documentation and can be used to search, filter, and sort note IDs and related information.

## Engineering and Validation Notes

- Application notes complement official documentation; they do not replace the **Datasheet**, **Reference Manual**, **Errata**, or development-tool documentation.
- Verify the exact MCU part number, family, package, silicon revision, permitted voltage levels, operating frequency, and pin limitations.
- Software examples may depend on a specific version of **MounRiver Studio (MRS)**, compiler, Peripheral Library, or firmware.
- Do not assume that features or pin mappings are identical across all CH32 devices without checking the relevant documentation.
- Validate hardware and firmware on the target platform before using them in a production design.
